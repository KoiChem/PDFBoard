# PDFBoard

ブラウザだけで動く、PDFページ編集アプリです。PDFファイルが外部サーバーに送信されることは一切ありません。すべての処理はあなたのブラウザの中で完結します。

## できること

- PDFを開いてサムネイル一覧表示（ズームスライダーで大きさ変更）
- ドラッグ＆ドロップでページ並び替え（複数ページをまとめて移動も可）
- ページの回転（左90° / 右90° / 180°）、複製、削除
- 別PDFをドロップして末尾にページ追加、空白ページ追加（A4 / A3 / B5 / B4 / A5 / レター）
- 全体保存（`元ファイル名_edited.pdf`）
- 選択ページの抽出（`元ファイル名_extract.pdf`）
- 選択ページの個別保存（1ページずつ別ファイル）
- CSVリネームルールで分割保存（例：`1-3,第1章` と書くと、その範囲を1つのPDFにまとめて `元ファイル名_第1章.pdf` で保存）
- Undo / Redo（最大50件）、キーボードショートカット、未保存警告

ページの選択は、クリック／タップするたびに選択が追加／解除される複数選択方式です（Shift+クリックで範囲選択、Ctrl+Aで全選択、ボードの空白部分をクリックで全解除）。右クリック（長押し）メニューからも各操作ができます。

## 使い方・起動方法（正式対応）

次のどちらかの方法で開いてください。

1. **GitHub Pages**：このリポジトリの GitHub Pages 公開URLをブラウザ（Chrome / Edge 最新版）で開く
2. **ローカルHTTPサーバー**：このフォルダで `python3 -m http.server 8000 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8000` を開く（インターネット接続は不要です）

> **index.html をダブルクリック（file://）では動作しません。**
> PDF.js のモジュール読み込みがブラウザのセキュリティ制限（CORS）でブロックされるためです。必ず上記のどちらかで開いてください。

初回読み込み時のみライブラリの取得に通信が必要な場合があります（GitHub Pages）。一度読み込めば、PDFの処理自体は完全オフラインで動作します。

## CSVリネームルールの書き方

1行に1ルール、`ページ番号,名前` または `範囲,名前` の形式で書きます。ページ番号は「現在の並び順」で数えた番号（1始まり）です。

```csv
1-3,第1章
4-6,第2章
7,参考資料
```

- 個別保存のとき、範囲で指定されたページは1つのPDFにまとめて保存されます
- CSVに書かれていないページは `元ファイル名_ページ番号.pdf` で保存されます
- 範囲が重なる行・範囲外の行・形式が違う行はスキップされ、画面に警告が出ます
- ファイル名に使えない文字（`/ \ : * ? " < > |`）は `_` に置き換わります

## 注意・制限

- **これは「ページ整理」専用アプリです。** しおり、入力フォーム、電子署名、注釈など、文書全体に関わる情報は保存時に保持されない場合があります
- パスワード付き（暗号化）PDFは開けません
- 元のPDFファイルは変更しません（保存は常に新しいファイルへのダウンロードです）
- 個別保存では複数ファイルのダウンロードが発生します。ブラウザが「複数ファイルのダウンロード許可」を求めた場合は許可してください
- ブラウザを閉じると編集中の内容は失われます（自動復元はありません）。設定（サムネイルサイズ、空白ページの既定サイズ、最後に使ったCSV名）だけがブラウザに保存されます
- 想定は約100ページまでのPDFです。100ページを超えると警告が出ます（動作はします）
- 対応ブラウザ：Chrome / Edge（最新版）。Firefox / Safari は動作保証外です

## セキュリティ

- PDFデータはブラウザのメモリ内だけで処理され、どこにも送信されません
- PDF表示ライブラリはサポート中の PDF.js 6.5.438 を使用し、`isEvalSupported: false`（PDF内スクリプトの評価を無効化）を常時指定しています
- ライブラリはすべてこのリポジトリに同梱しています（CDNは使いません）

## ファイル構成

```
index.html            画面
style.css             スタイル
app.js                アプリ本体（ESモジュール）
pdf.min.mjs           PDF.js 6.5.438（表示・サムネイル生成）
pdf.worker.min.mjs    PDF.js ワーカー
pdf-lib.min.js        pdf-lib 1.17.1（PDF編集・保存）
SPEC.md               仕様書（チャップとの作戦会議で確定した最終仕様）
```
